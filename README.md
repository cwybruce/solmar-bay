Solmar Bay is an original top-down 2D open-world crime game: drive around an invented coastal city, steal cars, dodge the police, and run four missions with cash and progression. Vanilla canvas, no libraries, no network calls.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.

## How to play

- WASD / arrow keys — move and drive
- E — enter / exit a car
- Mouse aim + click — shoot the pistol
- F — punch
- P — pause, G — save, L — continue, M — mute
